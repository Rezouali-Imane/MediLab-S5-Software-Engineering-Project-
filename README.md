# 🧪 MediLab - Medical Laboratory Management System

[![Java](https://img.shields.io/badge/Java-17-blue?logo=java&logoColor=white)](https://www.oracle.com/java/)  
[![MySQL](https://img.shields.io/badge/MySQL-8.0-blue?logo=mysql&logoColor=white)](https://www.mysql.com/)  
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

MediLab is a **desktop application** that streamlines medical laboratory operations. It manages the entire lifecycle of tests—from patient registration to test processing, result validation, and billing—ensuring efficiency, accuracy, and data security.

---

## ✨ Features

- 🔒 **Role-Based Access Control (RBAC):** Separate dashboards for Secretary, Technician, Financial Manager, Admin, and Super Admin.  
- 🏥 **Patient & Appointment Management:** Register patients and schedule appointments easily.  
- 🧬 **Test & Result Workflow:** Track test orders, input results, and validate reports.  
- 💰 **Billing & Payments:** Generate invoices and manage payments efficiently.  
- 🛡️ **Data Integrity & Security:** Protect sensitive medical data and enforce strict validation rules.

---

## 🛠️ Technology Stack

- **Language:** Java  
- **UI:** Java Swing  
- **Database:** MySQL  
- **Architecture:** Three-Tier (Presentation, Business Logic, Data Access)

---

## 🚀 Installation

1. Clone the repository:  
```bash
git clone git@github.com:Rezouali-Imane/MediLab-S5-Software-Engineering-Project-.git
```

2. Set up your database using database.sql.

3. Configure your database connection in config.example.

4. Run the application.
